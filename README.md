# trip-planner：說一句話，排好整趟旅行

跟 Copilot 說「幫我安排出國行程」，或直接講哪幾天、去哪裡。它問完幾個問題，就交給你一個 HTML 檔：每天幾點到哪、怎麼過去、大概花多少、下雨怎麼辦，都排在裡面。雙擊就能打開，不用安裝任何程式。

## 安裝

不需要 Python、Node 或任何程式，把資料夾放對位置就好。

### 適用平台

| 平台 | 裝在哪 | 實測狀況 |
|---|---|---|
| GitHub Copilot app | `~/.copilot/skills/trip-planner/`（方法一） | 已實測（2026-10-14，Windows） |
| GitHub Copilot CLI | 同上 | 已實測（2026-10-14，Windows，CLI 1.0.95） |
| VS Code 的 GitHub Copilot | 同上。[官方文件](https://code.visualstudio.com/docs/agent-customization/agent-skills)說也會讀 `~/.claude/skills/`、`~/.agents/skills/` | 依官方文件，本刊未實測 |
| Copilot Cowork（Microsoft 365） | 在 Cowork 裡上傳 ZIP，見下方方法三 | 未實測。Cowork 在雲端執行，封面腳本和存成 HTML 檔能不能正常跑還不確定 |

放進 `~/.copilot/skills/` 一次，GitHub Copilot app、CLI、VS Code 三個都讀得到。

先確認資料夾長這樣。`SKILL.md` 要直接放在 `trip-planner` 裡面，不要多包一層（解壓縮後常變成 `trip-planner\trip-planner\SKILL.md`，這樣會找不到）：


### 方法一：你自己在哪裡都能用（個人範圍）

把整個 `trip-planner` 資料夾複製到 `~/.copilot/skills/trip-planner/`。2026-10-14 實際用過這個路徑：GitHub Copilot app 可以，Windows 上的 GitHub Copilot CLI 1.0.95 也可以。VS Code 依官方文件也讀這個資料夾，本刊未實測；macOS／Linux【待實測】。

先看手上是哪一種：從典藏館網站下載的 `trip-planner.zip` 沒有外層資料夾，打開直接就是 `SKILL.md`，要先在 `skills` 裡建一個 `trip-planner` 資料夾，再解壓進去；電子報附件解壓後已經有外層 `trip-planner` 資料夾，整個複製過去就好。

**Windows**

1. 開「檔案總管」，在上方網址列輸入 `%USERPROFILE%\.copilot\skills`，按 Enter。
2. 打得開：把 `trip-planner` 資料夾整個拖進去，就完成了。
3. 打不開：代表資料夾還不存在。網址列改輸入 `%USERPROFILE%`，在裡面新增資料夾 `.copilot`，進去再新增 `skills`，然後回到第 2 步。

完成後，這個檔案應該存在：`C:\Users\你的帳號\.copilot\skills\trip-planner\SKILL.md`。

**Mac【待實測】**

1. 打開「終端機」，貼上下面這一行，按 Enter（資料夾已經存在也沒關係）：

   ```text
   mkdir -p ~/.copilot/skills
   ```

2. 在 Finder 按 `Shift`＋`Command`＋`G`，輸入 `~/.copilot/skills`，按 Enter。
3. 把 `trip-planner` 資料夾整個拖進去。

### 方法二：只在某個專案裡用（專案範圍）【待實測】

把整個 `trip-planner` 資料夾複製到那個專案（repo）的 `.github/skills/trip-planner/`。只有在這個專案裡開 Copilot 時才會用到；推上 GitHub 之後，同一個 repo 的同事也能用。

### 方法三：Copilot Cowork（Microsoft 365）【待實測】

Cowork 不讀本機資料夾，要上傳 ZIP（[官方說明](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-customize)）。上傳時 ZIP 不能有密碼，打開後 `SKILL.md` 要在最外層。手上的 ZIP 是哪一種，做法不同：

- **典藏館網站下載的 `trip-planner.zip`**：沒有密碼，`SKILL.md` 本來就在最外層，直接上傳，不用解壓。
- **電子報附件版**：有密碼，又多包一層 `trip-planner` 資料夾，不能直接傳，要先重新壓縮：
  1. 解壓附件 ZIP，進到 `trip-planner` 資料夾裡面。
  2. 全選裡面的檔案和資料夾（`SKILL.md`、`README.md`、`assets`、`references`），壓成一個沒有密碼的新 ZIP。打開新 ZIP 時，`SKILL.md` 要在最外層。

上傳：在 Cowork 左側選 **Customize** → **Skills**，按 **Add** 旁的箭頭 → **Upload skill**，選網站版 `trip-planner.zip` 或你重新壓好的 ZIP。

官方限制：單一 ZIP 最多 10 MB、100 個檔案；上傳後會存到你的 OneDrive。Cowork 在雲端執行，trip-planner 的封面腳本和存成 HTML 檔這兩步能不能正常跑，本刊還沒試過。
### 確認裝好了【待實測】

1. 重開 Copilot：CLI 關掉再開；VS Code 執行「Developer: Reload Window」。
2. 問它：「你有 trip-planner 這個 skill 嗎？」或直接說「幫我安排出國行程」試試。
3. VS Code 沒反應的話，到設定裡確認 Agent Skills 功能有開。

## 怎麼開始

三種說法都可以。

**1. 直接說「幫我安排出國行程」**

它會把 10 個問題一次列給你，照編號一題一題回，寫成一行就好：

> 1 釜山　2 10/19 出發 5 天　3 台北，17:00 到、回程 13:00　4 2 大人　5 還沒訂，想住西面　6 全部交給你　7 一定要去甘川洞　8 大眾運輸

沒寫到的題目，它會用預設。

**2. 一句話把細節講完**

> 10/19 從台北出發到韓國釜山，當日 17:00 到，共 5 天，回程下午 1 點的班機

它會先複述聽懂的部分（10/19～10/23，5 天 4 夜），只問缺的題目。住宿和交通沒講到的話，一定會問。講得越完整，要回答的就越少：

> 10/19 從台北出發到釜山，17:00 到，10/23 搭 13:00 的飛機回來。住西面的○○飯店，搭地鐵，兩大一小，步調放鬆

**3. 沒有反應時，明講「用 trip-planner 幫我…」**

> 用 trip-planner 幫我排 10/19 去釜山 5 天的行程

不管哪一種，最多問兩輪。沒回的題目用預設，但下面這幾件事，開排前一定會先跟你確認，就算你回「其他都用預設」也一樣：

- 查到的航班時刻（你只給了航班號時）
- 推定的護照（依出發地推定時）
- 小孩年齡（有小孩、但沒給年齡時）
- 特殊活動的細節（行程有滑雪、潛水、登山、主題樂園這類活動時）

在不能提問的環境（例如 CLI 的 `-p` 模式、排程執行），它不會停下來問：先照預設排，把推定、還沒確認的項目標出來，交件訊息第一段就列「需要你回覆」。★ 題缺了一樣不會排。

用哪個模型會影響行程的精細度。依我們的實測，偏推理的模型花的時間比較久，通常查證比較多。

每份行程都會同時附繁中和英文兩份內容，所以 AI 要多寫一份英文資料。我們用 Claude Opus 5.5 替兩份範例補英文版：輸出量約多四成（釜山多 44%、九州多 36%），時間約多三成（釜山 5 分鐘、九州 17 分鐘）。

### 10 個問題

| # | 問什麼 | 必答 | 沒回答、回「交給你」時 |
|---|---|---|---|
| 1 | 去哪裡（多個城市照順序寫） | ★ | — |
| 2 | 哪天出發、玩幾天 | ★ | — |
| 3 | 從哪裡出發；去程幾點到、回程幾點起飛 | ★ | — |
| 4 | 幾個人；小孩幾歲；長輩、行動不便、嬰兒車 | | 2 位大人 |
| 5 | 住宿訂了沒；沒訂的話想住哪區、預算 | | 它依路線推薦住宿區，每段附 3 家候選飯店 |
| 6 | 已經訂好的門票、餐廳、演唱會、一日遊 | | 全部交給它排 |
| 7 | 一定要去的、不想去的、飲食限制 | | 由它挑 |
| 8 | 交通：大眾運輸、計程車、自駕、混搭 | | 大眾運輸 |
| 9 | 步調、預算、總預算上限（選填）、每天幾點出門和回飯店、夜市夜景 | | 適中、標準、沒有上限、09:00–21:30 |
| 10 | 護照（同行者有沒有持其他護照）、生日或紀念日 | | 從台灣、香港、澳門出發的，依出發地推定護照，開排前會跟你確認；其他地方會直接問 |

必答題回「交給你」不算數，它會再問一次。

行程語言不用選：網頁一定同時附繁中和英文版，打開後可以自己切換。它跟你對話時，照你用的語言。

## 怎麼開檔

做好後，你會拿到一個 HTML 檔，例如 `trip-busan-2026-10-19.html`，存在你目前的資料夾（想存別的地方就跟它說）；還有一則說明：檔案在哪、三句話的行程亮點、用了哪些預設、哪些還沒查證、怎麼開檔、隱私說明。

1. **電腦直接開**：雙擊檔案，用瀏覽器打開。
2. **傳給同行者**：在電腦上打開後，按網頁的「產生分享版」，把產生的檔案傳過去。
3. **手機開檔**：版面支援手機（RWD）。**真機實測（2026-10-15，iPhone 17 Pro Max）**：用 Teams 傳給自己，在 Teams 裡直接點開，畫面正常，底部分頁也能切換。另外用 iPhone 13（Safari 引擎）和 Android Pixel 7（Chrome 引擎）的模擬器測過版面。在不執行 JavaScript 的檔案預覽裡打開，只會看到「需要啟用 JavaScript」的提示，改用瀏覽器開就好。在 Teams 這類 app 內預覽器裡，外部連結（導航、來源）和下載（.ics、分享版）可能被擋，【待實測】；被擋時，改用瀏覽器開。

分享版會另存一個新檔，檔名後面加上 `-share`。產生前可以勾選要隱藏的項目：

- 住宿的名稱、地址和候選飯店（預設隱藏）
- 預算和金額（預設隱藏）
- 同行者細節：人數、小孩年齡、飲食、行動需求、特殊日子（預設隱藏）
- 航班號、航空公司、航廈
- 預約資訊

被隱藏的資料會直接從檔案裡拿掉，不只是畫面上看不到；被拿掉的地點也不會出現在地圖上。景點、餐廳這類公開地點會留著。分享版的頁面上方會寫出隱藏了哪些項目。

### 想改行程

直接講，不用重來：

- 「只改第 3 天，想多一點購物」
- 「改成租車」
- 「換飯店：（新飯店名稱或地址）」
- 「重新查證這份行程」（建議出發前一週說一次：只重新查證，不重排）
- 「幫這份行程補英文版」（v1.5 以前做的檔案用：不重排，另存成 `-v2` 新檔）

它只會動相關的部分，再重新產生 HTML，並告訴你還有哪些地方跟著受影響。繁中和英文兩份會一起改。

## 它會幫你做這些事

- 從你的話抓出日期、目的地、抵達和回程時間、天數。
- 給了航班號，會查出是哪家航空公司（查得到也附航廈），查不到就標「未查證」。回程那天照「起飛前 3 小時到機場」往回推出發時間，也會寫在回程那天的行程裡提醒你。
- 最多問兩輪。只說要排，它一次列出 10 題（3 題必答，其他都有預設）；一句話就講了細節，它只問缺的。沒回的題目用預設，但有幾件事開排前一定會先跟你確認（見「怎麼開始」）；在不能提問的環境裡，則是先排好，交件時再請你確認。
- 你已經訂好的門票、餐廳、演唱會，時間和地點都不會動，其他行程繞著它排。一定要去的地方會盡量排進去，排不進去的會寫原因。
- 以你的飯店為中心：每天從飯店出發、回飯店結束，同一區的景點排在同一天，不走回頭路。
- 照真人的節奏排：走路用觀光的速度算，熱門景點預留排隊時間，不會讓你跨區折返，也會分配體力。
- 還沒訂飯店的話，它會照路線決定要不要換飯店，每一段推薦一個住宿區，附 3 家查證過的候選飯店（優先挑 Google 評分 4.0★ 以上且評論數 > 100 則，標明評分與評論則數）讓你挑；餐廳與咖啡店也優先挑 Google 評分 4.2★ 以上（評論數 > 100 則）的高口碑店家，並在每餐附上 1～2 家同區高分備選餐廳。
- 會查你出發那幾天的當季亮點，例如賞楓、滑雪、祭典，也會避開季節性關閉的設施。
- 細節也會顧到：交通票券划不划算、末班車、景點最後入場、帶小孩的休息時間、換飯店那天的行李，還有上網、插頭、保險這些行前準備。開排前會先告訴你大概要等多久。
- 有總預算上限就照上限排；超過會先調整，壓不下來就跟你說還差多少。
- 從香港出發或用香港用語的話，繁中版會改用香港的說法，例如的士、酒店、港鐵。
- 細到每一站：每站有開始和結束時間，每段移動寫交通方式、分鐘數和費用，每天都有雨天備案。
- 依交通方式換排法。租車會提醒停車和駕照；搭大眾運輸會寫交通卡和末班車；搭計程車會附上給司機看的當地文字地址。日本、韓國這類地方，店名和地址下面會多一行當地原文（例如韓文、日文），繁中和 English 模式都看得到。要不要租車、租哪幾天，也可以交給它判斷。
- 有小孩、長輩、行動不便或飲食限制，它會照著調整；旅途中有生日或紀念日，會建議餐廳並提醒訂位。也會依你的護照查入境規定，放進行前清單。
- 能上網的話，營業時間、公休日、預約、票價、匯率都附來源和查證日期。查不到的標「未查證」，不會自己編店名或數字。
- 「最大」「最高」「第一」「唯一」這類說法要有官方或一手來源。只有旅遊網站這麼說的，會寫成「常被稱為……」並附來源，或乾脆不寫。
- 預算換算回本國貨幣時，一律用國際中間價，也會註明匯率種類。換現鈔會比中間價貴，實際差多少以銀行牌價為準。
- 主要景點盡量各附一張 Wikimedia Commons 的照片，標出作者和授權。找不到就不放，不拿別處的圖充數。

做出來的 HTML 裡有：

- 封面：一張目的地的原創地標插圖（見下方「封面插圖」）
- 逐日時間軸，手機上也好讀
- 地圖（要連網）：總覽看全部天數，也可以只看某一天。各站照順序用虛線連起來，虛線只表示先後，不是實際走的路線。地圖載不出來時，改列各站的當地地址和導航連結
- 每一站的導航按鈕（在韓國以 Naver Map、KakaoMap 為主）
- 天氣預報：有網路時每次打開都重新抓；沒網路時怎麼顯示，見疑難排解「天氣怎麼顯示？」
- 品質檢查面板：自動檢查時間有沒有撞在一起、住宿有沒有漏、站和站之間的交通時間合不合理、一天的交通有沒有超過上限，並列出未查證的項目
- 繁中／English 切換（行程內容也會一起換成英文）、深色模式、列印版面。切到 English 時，介面、行程、地圖標籤、清單、預算都是英文；店名和地址的當地原文（例如韓文）兩種模式都會顯示，標成「韓文：…」或 "Korean: …"
- 雙語一致性檢查：開檔時比對繁中和英文兩份資料，對不上就在頁面頂端顯示警示條
- 分享版：一鍵產生隱藏住宿、預算等細節的檔案，傳給同行者（見「怎麼開檔」）
- 查證過期提醒：有資料查證超過 14 天，頁首會提醒你出發前再確認
- 景點照片、行事曆匯出、行前清單等，看範本版本有沒有做【待實測】

去好幾個城市的話，用住最多晚的那個城市挑圖。

macOS／Linux 用的 `set-cover.sh` 需要 perl，以及 perl 的 `JSON::PP`、`MIME::Base64` 模組。這兩個是 perl 核心模組，通常裝了 perl 就有。缺少的話封面會跳過，處理方式見疑難排解「封面沒出現」。

## 隱私與條款

- 檔案裡沒有任何 API 金鑰，也不需要登入任何帳號。
- 開檔後，查天氣、載入地圖和照片時，瀏覽器會把**目的地座標和你的 IP** 送給 Open-Meteo、OpenFreeMap、jsDelivr、Wikimedia。
- 行程內容（飯店、日期、航班）就寫在 HTML 檔裡。轉傳之前，想一下對方需不需要知道這些；不想給的，用「產生分享版」隱藏。
- 天氣用的是 Open-Meteo 免費版，限非商業用途。個人旅行可以使用；公務出差請自行評估。
- 行程是 AI 排的。訂位、買票、付款前請再確認一次，尤其是標「未查證」的項目。

## 已知限制

- 跨時區、多種貨幣是 v1.5 新增的網頁功能，實際表現以實測結果為準，測完會在這裡更新。
- English 模式的地圖底圖只顯示有英文或拉丁字母名稱的地名，沒有的就不顯示。各站的當地原文不受影響，一樣列在行程裡。
- 當地原文是 AI 查到才填的。查不到的店名、地址會留空，那一站就沒有當地原文那一行，要問路時用英文名稱或導航連結。

## 疑難排解

**沒網路時會怎樣？**
檔案照樣打開，完整行程和各站資訊（時間、地址、說明）都看得到，也能列印。地圖要連網。沒網路時，地圖頁和每天的行程頁改列各站的當地地址和導航連結，總覽頁改列住宿，沒有離線版的地圖；連上網路後按「重試」。導航連結和照片也要有網路才打得開、載得出來。天氣怎麼顯示，見下一題。

**天氣怎麼顯示？**
看手上有哪種資料：

- 有網路：抓即時預報。
- 沒網路，但這台裝置之前連著網路開過這個檔案：顯示上次存下的預報。
- 這台裝置沒開過，但行程附有歷年同期的氣候資料：顯示歷年同期。
- 兩種都沒有：顯示沒有天氣資料。

天氣預報大約只能看到未來 16 天。出發日還太遠時，有網路也抓不到預報，就照後兩條處理；等出發日進入預報範圍，重新打開同一個檔案就會換成預報，不用重新產生行程。旅行結束後再打開，也是照這個順序找資料。

**一堆項目標「未查證」**
通常是你用的 AI 工具不能上網，交件說明裡會寫。訂位前自己再查一次，或換到能上網的環境，請它「重新查證未查證的項目」。

**預算跟我實際換到的錢對不上**
預算用國際中間價換算。在銀行換外幣現金，用的是現鈔賣出價，會比中間價貴；刷卡則照信用卡的結算匯率算。實際差多少，以銀行牌價為準。

**有些景點沒有照片**
照片只用 Wikimedia Commons，而且要查得到作者和授權。找不到就不放，不會拿其他網站的圖充數。

**封面沒出現**
代表產生行程時沒有跑封面插圖的工具，例如你用的 AI 工具不能執行指令。網頁會自動把封面藏起來，行程內容不受影響，交件說明裡也會寫。想補上，在 Windows 的 PowerShell 執行下面這行（這是裝在個人範圍的路徑；裝在專案裡的話，換成那個專案的 `.github\skills\trip-planner`）：

```text
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.copilot\skills\trip-planner\assets\set-cover.ps1" -Html "trip-busan-2026-10-19.html" -City "釜山" -Country "KR"
```

`-City` 填目的地城市，`-Country` 填兩碼國家代碼。工具會一次寫入繁中和英文兩種插圖名稱，不用再指定語言；舊的 `-Lang zh-CN` 已經移除，傳了會報錯。macOS／Linux 改用 `bash` 執行 `set-cover.sh`，參數相同【待實測】。

**切到 English 還是看到中文，或是沒有語言切換按鈕**
先看頁面頂端有沒有警示條，再對照下面三種情況。

1. **沒有切換按鈕，頂端也沒有警示條**：這是 v1.5 以前做的檔案，裡面只有一份資料。**先開一個新對話**（原因見下一題），貼這段，`<你的帳號>` 和檔名換成你的：
   ```
   用 trip-planner 幫 C:\Users\<你的帳號>\Downloads\trip-busan-2026-10-19.html 補英文版，只補英文、不重排行程，另存新檔、原檔保留
   ```
   它會用新版範本另存一個 `-v2` 檔，補寫英文那份，行程不會重排。
2. **頂端有警示條**（有沒有切換按鈕都算）：檔案已經有繁中和英文兩份資料，只是英文版被停用，或英文那份還殘留中文字。這時**不要**請它「補英文版」，照下方「頁面頂端出現警示條」那題修現有的兩份資料。
3. **只有店名、地址下面標著 "Korean: …" "Japanese: …"（中文模式是「韓文：…」）的那一行是當地文字**：這是當地原文，刻意保留給你到當地用；日文名稱裡的漢字也屬於這一行。正常，不用處理。

**更新 skill 後，要開新對話**
已經在進行中的對話，Copilot 記得的是舊版 skill 的規則，不會自己重讀新版。我們實測過：在舊對話裡要求「補英文版」，它照舊版做法另存了一個純英文檔，沒有產生新版的雙語網頁。更新 skill 之後，開一個新對話再下指令。

**頁面頂端出現警示條，說兩種語言的資料對不上**
這份檔案已經有繁中和英文兩份資料，不是舊檔，不用再補英文版。警示條有兩種：

- **英文版被停用**（沒有切換按鈕，只顯示繁中）：英文那份還是範本的示範資料；或兩份的結構、數值對不上，例如只改了其中一份的時間；或繁中那份的語言標記不是 `zh-TW`。
- **英文版有瑕疵**（還能切換）：英文那份在當地原文和網址以外，還留著中日韓文字。

警示條會寫出原因，列出最多 5 個出錯的位置。開一個新對話，貼這段，`<你的帳號>` 和檔名換成你的，警示條的文字可以整段貼在後面：
```
用 trip-planner 修 C:\Users\<你的帳號>\Downloads\trip-busan-2026-10-19.html 的雙語警示：照頂端警示條列出的原因和位置，把英文那份修好、結構對齊繁中那份。只修資料，不重排行程、不重新查證，也不要另外補一份英文版
```

**打開後只看到錯誤訊息**
代表檔案裡的行程資料壞了。跟 Copilot 說：「trip-busan-2026-10-19.html 打不開，幫我檢查並修好裡面的行程資料」。

**沒有觸發（skill 沒有啟動）**
照順序試這三步：

1. 確認 `SKILL.md` 沒有多包一層資料夾，路徑要是 `…\skills\trip-planner\SKILL.md`，不是 `…\skills\trip-planner\trip-planner\SKILL.md`。
2. 重開 Copilot：CLI 關掉再開；app 重新啟動；VS Code 執行「Developer: Reload Window」。
3. 開頭直接點名，例如「用 trip-planner 幫我排 10/19 去釜山 5 天的行程」。

**公司網路打不開地圖**
有些公司網路會擋外部服務。地圖載入失敗（離線、地圖程式下載失敗、瀏覽器不支援 WebGL），或 15 秒內沒載完時，地圖頁和每天的行程頁會改列各站的當地地址和導航連結，總覽頁改列住宿。連上網路後按「重試」。地圖已經載好、之後才缺的圖磚不會觸發這個退路，缺的地方會留白。
